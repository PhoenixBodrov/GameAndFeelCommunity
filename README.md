Downloads appear under Assets on the release page. Use the attached pack ZIP, not the automatic source archive. Each release names its pack, exact game and loader versions, and validation status. Steampunk 1.3 is not available yet. Existing snapshots are not verified gameplay releases.

GitHub sign in is required to post. Logs and screenshots are optional: drag a file into the report editor after removing private details. Check existing reports and add evidence in comments when the same problem is already reported.

Install into a new profile folder and keep your previous installation and saves as backups. Development and private notes are kept in a separate private repository.
